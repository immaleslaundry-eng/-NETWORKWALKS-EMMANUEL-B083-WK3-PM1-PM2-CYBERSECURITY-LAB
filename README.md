# Week 3 Task: PDF Password Cracking with John the Ripper

## Objective
Demonstrate the ability to crack a password-protected PDF file by extracting its hash and using John the Ripper to recover the password.

## Tools Used
- **John the Ripper** – password cracking tool
- **Online hash calculator** (networkwalks.com) – used to generate the hash value from the PDF

## Steps
1. Obtained a password-protected PDF file.
2. Generated the hash value of the PDF using an online hash calculator.
3. Fed the resulting hash into John the Ripper.
4. Ran the cracking process against the hash.
5. Successfully recovered the plaintext password.
6. Used the recovered password to open the previously locked PDF, confirming the crack was successful.

## Result
✅ Password successfully cracked and PDF unlocked.

## Key Takeaways
- Reinforced understanding of how hash-based password cracking works in practice.
- Highlighted the importance of strong, complex passwords for sensitive documents.
- Hands-on experience with a core tool used in penetration testing and offensive security workflows.

## Disclaimer
This exercise was performed in a controlled learning environment on a file I had authorization to test, as part of a structured cybersecurity course. Techniques described here should only be used on systems/files you own or have explicit permission to test.
